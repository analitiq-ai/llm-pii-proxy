# Implementation Plan: PII-Scrubbing Proxy for Claude Code

**Branch**: `001-pii-scrubbing-proxy` | **Date**: 2026-11-21 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-pii-scrubbing-proxy/spec.md`

## Summary

This is a loopback HTTP gateway between Claude Code and the Anthropic API.

**Outbound**, each content leaf of a request goes through three stages, then a constant placeholder notice is
appended to `system` (FR-019) and the request is forwarded:
1. Escape text that already looks like a placeholder.
2. Replace every value already in the session's vault, which starts seeded with the operator's always-scrub
   list (FR-018), at word boundaries.
3. Detect new values: Presidio and spaCy for PII, gitleaks for secrets, and optionally the confidential pass,
   a Privatemode model that only ever sees already-scrubbed text. Spans on the never-scrub list are dropped.

**Inbound**, placeholders are restored in text and tool-input deltas as they stream.

The key design constraint, found during research: thinking-block signatures fingerprint the exact bytes sent
earlier, so a per-session leaf cache must re-send identical scrubbed bytes for unchanged history (research R3).
Concurrent requests share one in-flight scrub per leaf (single-flight), so they can't disagree on its bytes.

Build vs. adopt was settled by running PrivAiTe (research R0): it passed the signature test but fails FR-002,
FR-004 and structure preservation, so this is a build.

## Technical Context

**Language/Version**: Python 3.13 (uv-managed)

**Primary Dependencies**: Starlette, uvicorn, httpx, httpx-sse, pydantic-settings, presidio-analyzer, spaCy
`en_core_web_lg` 3.8.0 (parser disabled), gitleaks (external binary at the version pinned by spike S2, installed
by `scripts/install-gitleaks.sh` and checked at startup). `fastapi` is removed (research R9). Dev: Faker (corpus
generation), Hypothesis (property tests).

**Storage**: none. Process memory only (FR-008).

**Testing**: pytest, pytest-asyncio, respx (upstream and Privatemode mocked), Hypothesis for the holdback
restorer (every split point, random tokens, values and escape functions) and the boundary rule. A benchmark suite
over a labelled corpus generated by `tests/fixtures/make_corpus.py`: Faker for pattern PII and names, with known
spans, plus a hand-curated set for context-dependent PII; committed with its labels. Manual end-to-end
validation per quickstart V2, V5, V7 and V10, using the recorder harness from spike R0 (`scripts/e2e/`), outside
pytest because it calls the real API.

**Target Platform**: developer workstation, Linux or macOS, loopback only

**Project Type**: single-process local service (HTTP gateway)

**Performance Goals**: added time to first streamed byte under 0.5 s for typical requests (≤ 20 KB of new
content) with local detection only (SC-004). Unchanged history adds no detection cost (leaf cache).

**Constraints**: fail closed on any scrubbing failure. Re-sent history must be byte-identical. No content in
logs. Never touch thinking blocks. Stream event order preserved, with no buffering that could starve Claude
Code's idle timeout.

**Scale/Scope**: one developer, a few concurrent Claude Code sessions plus subagents. Requests up to several MB.

### Source Code (repository root)

```text
src/claude_pii_proxy/
├── __main__.py          # load Settings and operator lists, check gitleaks version, run uvicorn
├── config.py            # Settings (pydantic-settings); loopback-only validation; pinned gitleaks version
├── operator_lists.py    # always-scrub / never-scrub file loading and validation (FR-018)
├── app.py               # Starlette routes, upstream forwarding, proxy error responses, restart hint
├── sessions.py          # Session store: per-session Vault + single-flight leaf cache, idle eviction
├── vault.py             # Category, Placeholder token grammar, append-only Vault, seeding
├── scrub.py             # request walker (skip-list) + three-stage leaf pipeline + boundary rule
├── notice.py            # constant placeholder notice and its append to `system` (FR-019)
├── restore.py           # holdback restorer (text / JSON-escaped), non-stream JSON restore
├── sse.py               # upstream SSE events -> restored downstream SSE, order preserved
├── report.py            # ScrubReport counts, header, log line with session totals
└── detection/
    ├── __init__.py      # DetectedSpan, Detector protocol, edge trimming, overlap resolution
    ├── chunking.py      # line-based chunker with overlap, shared by NER and the confidential pass
    ├── presidio.py      # Presidio analyzer setup (parser disabled), entity -> Category map
    ├── gitleaks.py      # gitleaks stdin invocation, finding -> span mapping
    └── confidential.py  # Privatemode client: schema call, span location

scripts/
├── install-gitleaks.sh  # pinned release into .tools/, sha256-verified
└── e2e/                 # recorder + leak/thinking analysis from spike R0; manual, real API

tests/
├── unit/                # vault, grammar, holdback, walker, overlap, report
├── integration/         # Starlette app + respx upstream/Privatemode: no_leak, fail_closed, streaming, confidential
├── benchmark/           # labelled corpus recall for SC-003 / SC-005
└── fixtures/            # pii-project/, context-pii/, make_corpus.py + generated labelled corpus
```

**Structure Decision**: a single package with `src/` layout, as scaffolded. Each detector is a separate module
behind one `Detector` protocol, so the confidential pass plugs in without touching the pipeline (US2 is
independently deliverable).
